# squash-ai-coach

사람 코치 레슨 없이 AI에게만 배워서 첫 아마추어 스쿼시 대회(2026-11-22)에 나가는 38일 프로젝트의 도구 저장소입니다.
영상은 유튜브에 올리고, 이 저장소에는 분석 도구와 공개 대시보드, 분석 결과만 둡니다.

## 실행

1. `start.bat`을 더블클릭합니다. 검은 서버 창이 뜨고 잠시 뒤 브라우저에서 분석 앱(`http://localhost:8780/app/`)이 열립니다.
2. 작업하는 동안 서버 창은 닫지 마세요. 끝나면 서버 창을 닫으면 됩니다.
3. 대시보드는 `http://localhost:8780/docs/` 에서 미리 볼 수 있습니다.

맥: `start.command`를 더블클릭합니다(처음 한 번은 터미널에서 `chmod +x start.command`가 필요할 수 있음). python3과 Chrome이 필요합니다.

Chrome 또는 Edge를 쓰세요(분석 묶음 내보내기에 필요한 폴더 저장 기능이 이 둘에만 있습니다). 처음 실행할 때 MediaPipe 라이브러리를 인터넷(jsDelivr)에서 받으므로 인터넷 연결이 필요합니다. 자세 모델 파일은 저장소 안(`app/models/`)에 있습니다.

## 분석 앱 사용법

공통 순서는 세 단계입니다. 맨 위 탭 4개는 **같은 영상, 같은 분석 결과**를 다른 눈으로 보여 줄 뿐이라서 탭을 바꿔도 다시 분석하지 않습니다.

1. **열기** — 맨 위 [파일 열기]를 누르거나 영상 영역으로 영상을 끌어다 놓습니다. 앱이 약 2초 동안 fps(초당 프레임 수)를 재서 알아서 정합니다. 못 알아내면 빨간 안내가 뜨고, [30] [60] [120] [240] 중 하나를 고르기 전에는 전체 분석을 할 수 없습니다(아이폰 슬로모션은 보통 120, 일반은 30 또는 60).
2. **전체 분석** — 버튼을 한 번 누르고 끝날 때까지 기다립니다(1분 안팎). 끝나면 무릎이 크게 굽은 순간을 앱이 찾아 장면을 담아 둡니다. 분석이 끝났을 때 영상 종류가 달라 보이면 오른쪽 위에 "게임 분석 탭을 열어 보세요" 같은 안내가 뜹니다(제안일 뿐, 저절로 바뀌지 않음).
3. **내보내기** — [내보내기]를 누르고 이 저장소의 `sessions` 폴더를 고릅니다. 한 번 고르면 다음부터는 묻지 않습니다(브라우저가 허용만 다시 물어봅니다). 폴더를 바꾸려면 [고급 설정]의 "저장 위치 바꾸기".

**영상 파일은 `data/` 폴더에 두세요.** 이 폴더는 git에 올라가지 않습니다(영상은 유튜브로 갑니다).

### 탭 1. 자세 조정 (화·목 드릴)

- 위쪽 카드: 무릎이 크게 굽은 횟수, 평균 최저 무릎 각도, 평균 발 간격.
- "이번 주 체크": 이번 주 고칠 항목(영상 위 작은 상자에도 같은 3줄이 나옵니다). 초록 띠가 목표 범위, 세로 막대와 숫자가 내 값입니다. "근거 보기"를 누르면 코치 영상 출처가 펼쳐집니다. 어떤 항목을 보일지는 `app/checkpoints.json`의 `overlay_ids`에 있고 AI 코치가 매주 바꿉니다.
- "무릎이 크게 굽은 순간": 누르면 그 장면으로 갑니다. 그래프의 노란 점이 같은 순간입니다.
- 눈으로 보는 항목은 "눈으로 확인"을 펼쳐 통과/미달/해당없음을 직접 누르세요.

### 탭 2. 게임 분석 (토 게임)

1. 오른쪽 "코트 맞추기"의 [코트 맞추기]를 누르면 영상이 멈춥니다.
2. 목록에서 점 이름을 고르고, 영상에서 **바닥의 그 위치**를 누릅니다(다음 점은 자동으로 넘어감). 보이는 점만 **4개 이상**이면 됩니다. 선수가 가리면 프레임을 옮겨서 찍으세요.
3. 빨간 코트 선이 영상의 바닥 선과 겹치는지 눈으로 봅니다. 틀어졌으면 [되돌리기]나 점을 다시 눌러 옮깁니다.
4. 같은 이름의 영상이면 맞춤이 기억됩니다. [전체 분석] 뒤에 위쪽 카드에 T 점유율, 아래 지도에 이동 경로가 나옵니다. 점유율에는 랠리 사이 쉬는 시간도 들어갑니다.

2명이 나오는 영상이면 "분석할 사람"에서 내 쪽(1번/2번)을 고르세요. 범실 기록은 2주차에 추가됩니다.

### 탭 3. 스텝·체력 (고스팅 테스트)

코트 맞추기는 탭 2와 같습니다. 고스팅은 T에서 출발해 6코너를 3바퀴 도는 **18회**가 정상이고, 아니면 "18회가 아님"이 뜹니다. 위쪽 카드에 총시간·방문 횟수·가장 느린 코너가 나오고, 그래프에는 코너별 평균 시간이 막대로 나옵니다(노란 막대가 가장 느린 코너).
회복 심박: 테스트 끝난 직후 심박을 A, 1분 뒤를 B에 적으면 A-B가 자동으로 나옵니다. 내보내기 때 같이 저장됩니다.

### 탭 4. 변화 기록

[sessions 폴더 연결]을 누르고 `sessions` 폴더를 고르면(다음부터는 자동), 내보낸 기록이 날짜순 표로 나옵니다. 각 칸 아래의 작은 글씨가 **직전 기록과의 차이**입니다(초록 = 좋아짐, 빨강 = 나빠짐, 회색 = 방향 없음). 지표: 무릎 굽힘(평균 최저), 평균 발 간격, T 점유율, 고스팅 총시간, 가장 느린 코너, 회복 심박. 값이 없으면 "기록 없음"입니다. 오른쪽에는 지표별 변화 그래프가 있습니다. 폴더 연결을 지원하지 않는 브라우저에서는 [폴더 여러 파일 선택]을 쓰세요.

### 그 밖의 기능

- 단축키(맨 위 "단축키"에도 있음): `Space` 재생/정지, `←` `→` 1프레임, `Shift`+화살표 10프레임, `C` 이 장면 담기, `F` 전체화면(`Esc`로 돌아옴). 전체화면에서도 뼈대·체크 상자·단축키가 그대로 됩니다.
- 그래프나 지도를 누르면 그 장면으로 이동합니다.
- [고급 설정]: fps, 분석 간격, 각도(2D 화면 / 3D 추정), 라켓 손, 뼈대 표시, 영상 위 체크 표시, 묶음 이름. 3D는 추정값이라 2D와 숫자가 다를 수 있고, 자동 감지는 2D 기준으로 맞춘 값입니다.
- 내보낸 폴더에는 `meta.json`, `angles.csv`(코트 위치 `court_x`, `court_y` 포함), `events.json`(자동 감지), `court.json`(코트 맞춤·T 점유율·고스팅·회복 심박), `captures.json`, `frames/*.png`가 들어갑니다.
- 아이폰 영상(HEVC)이 안 열리면 터미널에서 변환합니다: `ffmpeg -i in.mov -c:v libx264 -crf 18 -an out.mp4`

## 영상 비교 화면

위의 "영상 비교 화면" 링크(`app/compare.html`)로 갑니다. 왼쪽(A)에 코치 영상, 오른쪽(B)에 내 영상을 열거나, 1주차와 4주차 영상을 엽니다. 패널을 눌러 선택한 뒤 방향키로 따로 이동하고, "동기 이동"을 켜면 함께 움직입니다. 두 영상의 같은 동작에서 각각 "여기를 맞춤점으로"를 누르면 그 지점을 기준으로 맞춰집니다.
"비교 이미지 저장"은 두 프레임과 각도 비교표를 한 장의 PNG(`compare-날짜-시간.png`)로 내려받습니다. 대시보드에 쓰려면 `docs/media/`로 옮기세요.

## 폴더

| 경로 | 내용 |
|---|---|
| `start.bat` | 로컬 서버(포트 8780)를 띄우고 분석 앱을 엽니다 |
| `app/` | 분석 앱. `index.html`(분석 화면), `compare.html`(비교 화면), `pose.mjs`(공유 모듈), `angles.mjs`(각도 계산), `court.mjs`(코트 규격·위치 계산), `history.mjs`(변화 기록 계산), `checkpoints.json`(체크포인트 정의), `models/`(MediaPipe 자세 모델, Apache-2.0) |
| `docs/` | 공개 대시보드(GitHub Pages가 이 폴더를 게시). `data/*.json`이 데이터, `media/`는 대시보드용 이미지 |
| `sessions/` | 분석 앱이 내보낸 분석 묶음 |
| `data/` | 내 영상 보관용(git에 올라가지 않음) |
| `tests/check.mjs` | 점검 스크립트. `node tests/check.mjs` |

영상 파일(`*.mp4`, `*.mov`, `*.m4v`)과 `data/` 폴더는 저장소에 넣지 않습니다(`.gitignore`). 영상은 유튜브로 갑니다.

## 대시보드 데이터

`docs/data/`의 JSON 파일을 고치면 대시보드가 바뀝니다. 형식은 `SPEC.md` 3절을 따릅니다.

- `project.json` 프로젝트 정보와 판정 지표 5개
- `sessions.json` 훈련 일지
- `metrics.json` 지표 측정값(지표마다 첫 값이 기준선)
- `prescriptions.json` 주간 처방
- `reports.json` 주간 코치 리포트
