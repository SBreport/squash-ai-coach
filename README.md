# squash-ai-coach

사람 코치 레슨 없이 AI에게만 배워서 첫 아마추어 스쿼시 대회(2026-11-22)에 나가는 38일 프로젝트의 도구 저장소입니다.
영상은 유튜브에 올리고, 이 저장소에는 분석 도구와 공개 대시보드, 분석 결과만 둡니다.

## 실행

1. `start.bat`을 더블클릭합니다. 검은 서버 창이 뜨고 잠시 뒤 브라우저에서 분석 앱(`http://localhost:8780/app/`)이 열립니다.
2. 작업하는 동안 서버 창은 닫지 마세요. 끝나면 서버 창을 닫으면 됩니다.
3. 대시보드는 `http://localhost:8780/docs/` 에서 미리 볼 수 있습니다.

맥: `start.command`를 더블클릭합니다(처음 한 번은 터미널에서 `chmod +x start.command`가 필요할 수 있음). python3과 Chrome이 필요합니다.

Chrome 또는 Edge를 쓰세요(분석 묶음 내보내기에 필요한 폴더 저장 기능이 이 둘에만 있습니다). 처음 실행할 때 MediaPipe 라이브러리를 인터넷(jsDelivr)에서 받으므로 인터넷 연결이 필요합니다. 자세 모델 파일은 저장소 안(`app/models/`)에 있습니다.

## 분석 앱 사용법 (3단계)

1. **열기** — 위의 파일 선택 버튼을 누르거나 영상 영역으로 영상을 끌어다 놓습니다. 열자마자 앱이 알아서 fps(초당 프레임 수)를 재서 fps 칸에 넣고 "자동 감지" 표시를 붙입니다. 약 2초 걸립니다. 간격 칸도 fps에 맞춰 자동으로 정해집니다. 라벨도 영상 파일 이름으로 자동 입력됩니다.
2. **전체 분석** — 버튼을 한 번 누르고 끝날 때까지 기다립니다(영상 길이에 따라 1분 안팎). 끝나면 앱이 무릎이 굽는 순간을 자동으로 찾아 그 프레임을 하나씩 "담기"까지 해 줍니다. 오른쪽 "무릎 굽힘 순간 자동 감지"에 목록이 생기고, 누르면 그 장면으로 이동합니다. 그래프의 노란 점이 그 순간입니다.
3. **내보내기** — "분석 묶음 내보내기"를 누르고 이 저장소의 `sessions` 폴더를 고릅니다. 전체 분석을 안 하고 누르면 "각도 데이터가 비어 있습니다" 경고가 뜹니다.

영상 위에는 "이번 주 체크" 작은 상자(최대 3줄)만 나옵니다. 어떤 항목이 나올지는 `app/checkpoints.json`의 `overlay_ids`에 적혀 있고 AI 코치가 매주 바꿉니다. 나머지 항목은 오른쪽 체크포인트 패널에 그대로 있습니다. 끄려면 "영상에 표시" 체크를 해제하세요.

### 코트 맞추기 (T 점유율, 이동 지도, 고스팅 시간)

1. 영상을 열고 오른쪽 "코트 맞추기" 버튼을 누릅니다. 영상이 멈추고, 목록에 "지금 찍을 점"이 나옵니다.
2. 목록에서 점 이름을 고르고, 영상에서 **바닥의 그 위치**를 클릭합니다. 다음 점은 자동으로 넘어갑니다. 뒷벽 쪽에서 찍었다면 보이는 것은 앞벽 바닥 모서리, 숏라인(앞벽 쪽 가로선)과 옆벽이 만나는 곳, T(숏라인과 가운데 세로선이 만나는 곳), 서비스박스 뒤쪽 안 모서리입니다. 선수가 가리면 프레임을 옮겨서 찍으세요. 안 보이는 점은 건너뛰세요.
3. **보이는 점만 4개 이상** 찍으면 빨간 코트 선이 영상에 겹쳐 그려집니다. 바닥 선과 맞는지 눈으로 보세요(숫자 "선 맞춤 오차"는 작을수록 좋음). 틀어졌으면 "되돌리기" 또는 점을 다시 눌러 옮기세요. 점이 많고 퍼져 있을수록 정확합니다.
4. 같은 삼각대 자리면 같은 이름의 영상에서 맞춤이 기억됩니다. 그 뒤 "전체 분석"을 하면(이미 했다면 바로) 영상 아래 "코트 이동 지도"에 T 점유율과 고스팅 방문 표가 나옵니다. 고스팅은 T에서 출발해 6코너를 3바퀴 도는 18회가 정상이고, 아니면 "18회가 아님" 경고가 뜹니다. 점유율에는 랠리 사이 쉬는 시간도 들어갑니다.

**영상 파일은 `data/` 폴더에 두세요.** 이 폴더는 git에 올라가지 않습니다(영상은 유튜브로 갑니다).

그 밖의 기능:
- `Space` 재생/정지, `←` `→` 1프레임 이동, `Shift`+화살표 10프레임 이동, `C` 이 프레임 담기(직접 원하는 장면을 담을 때)
- fps 자동 감지가 틀렸거나 "fps 확인 필요"가 뜨면 fps 칸에 촬영 fps를 직접 넣으세요(간격은 따라 바뀝니다).
- 그래프를 누르면 그 프레임으로 이동합니다.
- 라켓 손(오른손/왼손)과 각도 모드(2D 화면 / 3D 추정)는 위 칸에서 고릅니다. 현재 모드는 영상 위에도 표시됩니다. 3D는 MediaPipe 추정값이라 2D와 숫자가 다를 수 있고, 자동 감지는 2D 기준으로 맞춰 둔 값입니다.
- 체크포인트: 정의는 `app/checkpoints.json`(근거 링크 포함). 눈으로 보는 항목은 오른쪽 패널에서 통과/미달/해당없음을 직접 누릅니다. 런지 항목은 런지 드릴 영상에서만 의미가 있습니다.
- 내보낸 폴더에는 `meta.json`, `angles.csv`(코트 위치 `court_x`, `court_y` 포함), `events.json`(자동 감지 결과), `court.json`(코트 맞춤·T 점유율·고스팅 구간), `captures.json`, `frames/*.png`가 들어갑니다.
- 아이폰 영상(HEVC)이 안 열리면 명령 프롬프트에서 변환합니다: `ffmpeg -i in.mov -c:v libx264 -crf 18 -an out.mp4`

## 영상 비교 화면

위의 "영상 비교 화면" 링크(`app/compare.html`)로 갑니다. 왼쪽(A)에 코치 영상, 오른쪽(B)에 내 영상을 열거나, 1주차와 4주차 영상을 엽니다. 패널을 눌러 선택한 뒤 방향키로 따로 이동하고, "동기 이동"을 켜면 함께 움직입니다. 두 영상의 같은 동작에서 각각 "여기를 맞춤점으로"를 누르면 그 지점을 기준으로 맞춰집니다.
"비교 이미지 저장"은 두 프레임과 각도 비교표를 한 장의 PNG(`compare-날짜-시간.png`)로 내려받습니다. 대시보드에 쓰려면 `docs/media/`로 옮기세요.

## 폴더

| 경로 | 내용 |
|---|---|
| `start.bat` | 로컬 서버(포트 8780)를 띄우고 분석 앱을 엽니다 |
| `app/` | 분석 앱. `index.html`(분석 화면), `compare.html`(비교 화면), `pose.mjs`(공유 모듈), `angles.mjs`(각도 계산), `court.mjs`(코트 규격·위치 계산), `checkpoints.json`(체크포인트 정의), `models/`(MediaPipe 자세 모델, Apache-2.0) |
| `docs/` | 공개 대시보드(GitHub Pages가 이 폴더를 게시). `data/*.json`이 데이터, `media/`는 대시보드용 이미지 |
| `sessions/` | 분석 앱이 내보낸 분석 묶음 |
| `data/` | 내 영상 보관용(git에 올라가지 않음) |
| `tests/check.mjs` | 점검 스크립트. `node tests/check.mjs` |

영상 파일(`*.mp4`, `*.mov`, `*.m4v`)과 `data/` 폴더는 저장소에 넣지 않습니다(`.gitignore`). 영상은 유튜브로 갑니다.

## 대시보드 데이터

`docs/data/`의 JSON 파일을 고치면 대시보드가 바뀝니다. 형식은 `SPEC.md` 3절을 따릅니다.

- `project.json` 프로젝트 정보와 판정 지표 5개
- `sessions.json` 훈련 일지
- `metrics.json` 지표 측정값(지표마다 첫 값이 기준선)
- `prescriptions.json` 주간 처방
- `reports.json` 주간 코치 리포트
